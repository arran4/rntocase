Usage: rntocase dot [flags...] [files...]

Rename files to dot case

Examples:
rntocase dot --delimiter "." --dry-run "hello world"
rntocase dot -interactive *

Flags:
    --delimiter string    The delimiter to use
    --dry-run             Print the rename operations to be performed without executing them
    --interactive         Prompt for confirmation before executing each rename operation

Positional Arguments:
    files      (min: 1) The files to rename

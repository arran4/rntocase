Usage: rntocase upperleading [flags...] [files...]

Rename files with an upper leading character

Examples:
rntocase upperleading --dry-run "hello world"
rntocase upperleading -interactive *

Subcommands:

    usage        Print this usage message


Flags:
    --dry-run         Print the rename operations to be performed without executing them
    --interactive     Prompt for confirmation before executing each rename operation

Positional Arguments:
    files      (min: 1) The files to rename

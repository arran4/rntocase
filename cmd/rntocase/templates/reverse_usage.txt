Usage: rntocase reverse [flags...] [files...]

Reverse characters or words in file names

Examples:
rntocase reverse --dry-run "hello world"
rntocase reverse --word-mode -interactive *

Subcommands:
    help         Print this help message
    usage        Print this usage message


Flags:
    --word-mode       Reverse words instead of characters
    --dry-run         Print the rename operations to be performed without executing them
    --interactive     Prompt for confirmation before executing each rename operation

Positional Arguments:
    files      (min: 1) The files to rename

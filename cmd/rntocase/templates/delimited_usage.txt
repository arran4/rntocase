Usage: rntocase delimited [flags...] [files...]

Rename files with a custom delimiter

Examples:

rntocase delimited --delimiter "_" --dry-run "hello world"
rntocase delimited --delimiter "-" -interactive *

Subcommands:
    help         Print this help message
    usage        Print this usage message


Flags:
    --delimiter string   (default: "")   The delimiter to use
    --ignore string      (default: "")   The characters to ignore
    --json                               Output in JSON format
    --dry-run                            Print the rename operations to be performed without executing them
    --interactive                        Prompt for confirmation before executing each rename operation
    --recursive, -R                      Recursively traverse directories
    --include []string                   (type: []string) Include files matching pattern
    --exclude []string                   (type: []string) Exclude files matching pattern

Positional Arguments:
    [files...] (min: 1) The files to rename

Usage: rntocase skill install [flags...] <source> [nameOrPath]

Install a skill

Examples:

rntocase skill install --ref v1.2.0 --path skills/example --name example owner/repo

Subcommands:

Flags:
    --scope string          (default: "project")   Installation scope: user or project
    --agent string          (default: "common")    Target agent
    --replace                                      Replace existing skill
    --ref string                                   Specific Git ref
    --path string                                  Repository subdirectory
    --name string                                  Local skill name

Positional Arguments:
    <source>   (min: 1) Source repository/path
    [nameOrPath] Optional fallback name/path
